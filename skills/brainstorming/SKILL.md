# Proportionate design exploration

Adapted from Superpowers brainstorming: understand intent before committing to a
solution. Read relevant project code/design and shared experience first. Separate
known requirements from assumptions. For a material unresolved choice compare two
or three options, costs and verification methods. Ask only the questions whose
answers change the design; existing explicit requirements are already authorized.
Record substantial agreed decisions in the project's normal design document.
For a clear small task, state the assumption and implement without a plan document.
For a larger accepted design use writing-plans. Delegate bulky research
(datasheets, existing code, prior art) per delegating-work. Do not launch a
visual server, design-review loop or an approval ritual by default.
