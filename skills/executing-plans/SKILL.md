# Execute inline

Adapted from Superpowers executing-plans. Read the plan and authoritative
requirements. Inspect status and preserve changes outside your scope. Implement
one meaningful step at a time, verify it with the appropriate test/check, and
record deviations that change assumptions or interfaces. Use systematic-debugging
on failures rather than patching to satisfy a guessed result.

Do not dispatch agents, select other models, require worktrees or wait for approval
between already authorized steps. A small task needs no plan ledger. For larger
work maintain brief progress in the project's existing plan. At completion inspect
the full scoped diff with requesting-code-review (self-review is permitted and
must be labeled), run relevant checks and record reusable experience. Never delete
verification evidence or another agent's workspace as cleanup. Commit only the
assigned changes when authorized; no automatic merge/force-push.
